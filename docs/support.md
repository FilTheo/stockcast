# Citation and support

## Getting help

- **Questions and ideas:** open a discussion or issue on the
  [GitHub repository](https://github.com/FilTheo/stockcast/issues).
- **Bugs:** open an issue with a small example that reproduces it. Including
  the run manifest (`result.run_manifest`) helps a lot: it records the
  versions and settings behind a result.

## Citing Stockcast

A citable archive record will accompany the first public release. Until then,
please cite the Stockcast version and the repository release tag or commit you
used, for example:

```text
Theodosiou, F. Stockcast: forecast-driven inventory decisions, simulation, and
evaluation in Python. Version 0.1.0. https://github.com/FilTheo/stockcast
```
